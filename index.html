LLM gateway · deployed on Cloud Run

ThriftLLM

A cost-optimized LLM router with verified escalation. It answers with the cheapest model that can be trusted, and checks that before paying for a bigger one.

Live demo GitHub
82%cheaper than a frontier model
41%cheaper than a mid-tier model
~7 msprompt difficulty classification
94%of bad cheap answers caught
  • OpenAI-compatible gateway with multi-user auth, cost tracking and encrypted key storage. On a 116-query, three-difficulty benchmark, all 76 objectively graded answers were correct.
  • Routing policy minimizes expected cost (generation + verification + escalation) under a 0.80 per-difficulty accuracy floor. The routing map is derived automatically by calibrating any user-supplied model.
  • Similarity-weighted k-NN vote over sentence embeddings classifies difficulty with no LLM call, raising accuracy from 56.0% to 64.7%.
  • Two-stage verification: a logistic-regression confidence gate over token logprobs, then a $0.00004 LLM judge before escalation.

03About

A bit about me

I studied Electronics and Instrumentation at NIT Agartala, which is a roundabout way to end up in LLM infrastructure. It taught me to treat systems as signals: measure first, then tune.

That habit shows up everywhere in my work. A RAG platform is only as good as its parsing, retrieval and guardrails, so I instrument each layer. A router is only worth running if it saves money without losing accuracy, so ThriftLLM ships with a benchmark, not just a claim.

Before AI, I spent a lot of time on algorithms: 600+ problems solved across LeetCode and GeeksforGeeks. I also know networking well (TCP/IP, OSPF, RIP and packet analysis), which helps when the users of my RAG platform are network engineers.
